# Release scope

This repository is a results preview while ButterflyGate research continues.

## Public

- Curated measurements, including slower configurations, quality metrics where available, and unsuccessful-run status.
- Essential measurement conditions, sampling limits, artifact checksums, and interpretation.
- Figures and the code that generates them from released tables.
- An independent generic block benchmark that accepts a user-supplied module.

## Private

The mechanism, reference implementation, exact configuration mappings, model integration, internal diagnostics, training work, and operational records are not included. Anonymous configuration labels carry no architectural specification.

No private repository history is imported. Public tables use a fixed column allowlist; free-text internal notes and errors are replaced by defined status categories. Private source paths and source-to-label mappings remain outside this repository.

## Coverage of this release

The release covers three selected full-model experiment families from May 2026. Tiny plumbing checks, earlier standalone block experiments, and internal diagnostics are outside this release. They should not be inferred to have succeeded, been validated, or been superseded by a completed result.

Publication of these observations does not commit to a release date for the method or a research roadmap. Already-public information may remain accessible in repository history; this release boundary governs the new material.
