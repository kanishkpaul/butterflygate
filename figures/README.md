# Figures

Every figure is generated by [`scripts/plot_results.py`](../scripts/plot_results.py) using only public CSV files. PNG files are embedded in the reports; SVG versions support resizing and reuse.

The cover mark is decorative and does not represent the private architecture.

A throughput ratio above 1 means a faster recorded evaluation. Hollow 512-token markers flag cold-run observations; all points retain the broader timing caveats. Lines connect observations for readability and do not establish behavior between measured lengths. Missing 8B cells are quota-blocked, not zero. No confidence intervals are available.
